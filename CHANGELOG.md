## [1.0.0] - 2026-10-05

### Added
- Hỗ trợ mở khóa và tải PDF chất lượng cao từ **Studocu**, **Scribd**, và **SlideShare**.
- Giao diện Popup hiện đại theo phong cách Shadcn UI, hỗ trợ đa ngôn ngữ (Tiếng Việt & English).
- Background service worker quản lý luồng tải và mở tab an toàn.
- Hệ thống CI/CD tự động kiểm tra cú pháp, hợp lệ manifest và đóng gói file zip phân phối.
- Quy chuẩn Git Workflow, Pull Request và Issue templates cho môi trường production.
